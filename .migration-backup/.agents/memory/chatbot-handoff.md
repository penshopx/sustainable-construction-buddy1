---
name: Chatbot handoff
description: Batas perilaku chatbot publik LKUT-PUB-LSBUKI dan handoff ke workspace aplikasi
---

Chatbot publik LKUT-PUB-LSBUKI harus menjadi pintu masuk, bukan tempat utama untuk menyimpan data atau menyelesaikan proses. Pola yang digunakan adalah Navigator → Guided Intake singkat → CTA ke aplikasi; setelah login, chatbot berfungsi sebagai Workspace Assistant untuk mengarahkan ke fitur internal.

**Why:** Jawaban informatif saja mudah membuat user berhenti di chat dan mengandalkan ringkasan yang bukan keputusan resmi. Data pribadi, dokumen, checklist, progres, dan tindakan harus memiliki satu sumber kebenaran di aplikasi.

**How to apply:** Pertahankan mode publik pada pertanyaan umum, pengarah kebutuhan, dan intake sementara. Untuk status personal, penyimpanan, upload, checklist, atau tindakan, arahkan ke route aplikasi dan tampilkan batasan bahwa chat bukan validasi atau pengajuan resmi.
